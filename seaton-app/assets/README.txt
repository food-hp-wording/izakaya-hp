このフォルダにアイコン画像を置いてください。

必要なファイル:
- icon.png        : 1024x1024px（App用アイコン）
- splash.png      : 1242x2688px（スプラッシュスクリーン）
- adaptive-icon.png : 1024x1024px（Android用）

手順:
1. Canvaや Figma でシンプルなアイコンを作成
   - 白背景 + ミントグリーン(#00C9A7)の文字 "S" か手をつなぐイラスト
2. PNGでエクスポートして上記ファイル名で保存

暫定アイコンの作成（ターミナルで）:
  npx create-expo-app@latest でプロジェクト作成時に自動生成される場合あり

テスト中はデフォルトのExpoアイコンでも動作します。
